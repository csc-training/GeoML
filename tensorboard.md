# TensorBoard

1. Log in via web interface: [LUMI](https://www.lumi.csc.fi/public/) or [Puhti](https://puhti.csc.fi)
3. Select menu item: Apps → TensorBoard
4. In the form:
   - Select your project
   - Specify the "TensorBoard log directory". You can run `pwd` in the terminal to find out the full path where you are working.
   - Leave rest at default settings
6. Click "Launch"
7. Wait until you see the "Connect to Tensorboard" button, then click that.
8. When you're done using TensorBoard, please go to "My Interactive Sessions" in the web user interface and "Cancel" the session. (It will automatically terminate once the reserved time is up, but it's always better to release the resource as soon as possible so that others can use it.)
